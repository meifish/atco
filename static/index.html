PDF parsing details and limitations

Pages are compared by page number and original coordinates, rounded to 0.1 pt. Pages that were shifted, scaled or reordered are not aligned automatically. A change is shown as the old object removed plus the new object added; this is not CAD element recognition. Text changes are grouped by word, and the small filled glyph paths that belong to the text are merged into it instead of being listed separately. Regions are a way to navigate, not a count of changes. Scanned pages are compared as images, with no OCR. Layer visibility, clipping, transparency and special drawing effects still need a manual check.
